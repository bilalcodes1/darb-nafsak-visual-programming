# درب نفسك | Visual Programming

واجهة عربية أولاً لمراجعة أسئلة Visual Programming (C#) للأسبوعين الخامس والسادس.

## تشغيل محلي

```bash
npm install
npm run dev
```

ثم افتح الرابط الذي يعرضه Vite. ولإنشاء نسخة إنتاجية:

```bash
npm run build
```

## المزايا

- بنك الأسئلة الأصلي كاملًا (120 سؤالًا) من `public/Week5_Week6_MCQs.json`
- وضع التعلّم، التدريب السريع، مراجعة الأخطاء، التحدّي، ومحاكاة الامتحان
- حفظ التقدم والإجابات والمحفوظات محليًا عبر `localStorage`
- واجهة RTL عربية مع عرض الأسئلة والخيارات الإنجليزية باتجاه LTR
- وضع ليلي، تكبير النص، دعم لوحة المفاتيح، وتصميم mobile-first
